# 大肥鱼网页开通版 1.1.0-beta3

修复日期：2026-11-05。插件 v1.1.1，开通步骤不变。

- 记忆策略统一由插件提供。兼容旧模板时只替换发给模型的那句旧规则，不改数据库中的自定义人格。
- 自动记忆仍默认关闭，手动保存可用；保存和删除工具返回明确的成功或失败结果，存储错误不会伪装成成功。
- `/鱼状态` 读取当前会话配置的模型，支持会话单独选模型；读取失败显示未知，不再固定声称 DeepSeek。配置值不等于上一条请求实际使用的模型。
- 状态同时显示自动记忆开关、互动次数和记忆数量。
- 新增 11 项插件行为回归测试；测试使用独立数据库，不覆盖现有记忆。

本安装包用于首次部署，重复运行不是已有实例的升级命令。旧版本发布文件保留。

# 历史版本：1.1.0-beta2

发布日期：2026-11-04。

- 修复 QQ 群成员只发送 @、没有正文时不回复的问题。安装时为固定版本 AstrBot 4.29.4 应用已验证的兼容补丁。
- 同步已上线的大肥鱼记忆插件 v1.1.0，支持按群、发言者隔离的手动记忆、可选自动整理、检索和删除。
- 新建默认人格绑定全部五项大肥鱼工具。自动记忆默认关闭，每位用户可用 `/鱼自动记忆 开启` 启用，并用 `/鱼记忆` 查看。
- 部署入口指向有独立版本号的安装包和 ROS 模板，旧版文件保留。

本安装包用于首次部署。重复执行会保留已安装配置，并不自动升级已有实例。
现有演示服务器已通过群友单独 @、@ 加文字的 QQ 实测。本次发布不修改现有账号、人格、聊天、记忆或 QQ 绑定。
新用户需要自己的同款服务器、套餐模型密钥和 QQ 授权。机器人仍需联网，模型用量计入套餐额度。
另一台全新同款服务器的完整首次安装尚未验收。

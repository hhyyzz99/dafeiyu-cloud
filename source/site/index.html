🐋 大肥鱼网页开通版 · 1.1.0-beta2
在自己的服务器上，养一条鱼

买好服务器，
接下来交给大肥鱼。

不用上传文件，不用输入安装命令。
在阿里云确认部署，再用网页完成开通。

01

准备同款服务器

阿里云轻量应用服务器 · 智能体专用型
北京 / 2 核 6 GB / 30 GB / 每月 12,500 Credits
选择 Hermes Agent 应用镜像。

打开服务器控制台 ↗服务器购买费用以实际订单为准。本页不会代购。
02

确认部署

在服务器概览复制实例 ID，进入阿里云部署页面。安装程序会使用 80、443 端口，并为公网 IP 申请免费可信证书。

一键部署大肥鱼 →兼容同款 Hermes 镜像；443 被其他网站占用时会停止。
03

打开自己的鱼塘

在部署结果中打开你的专属开通链接，设置管理密码，粘贴自带的模型密钥，最后用 QQ 扫码确认。

设置密码 → 激活模型 → 扫码聊天专属开通链接含一次性开通码，请勿分享给别人。
部署前，再确认这三件事

① 服务器位于北京，处于运行中，命令助手正常。
② 公网 80、443 端口可访问，443 未被其他网站占用。
③ 提前复制此服务器的模型 API Key；使用的是套餐自带 DeepSeek，无需另开百炼付费密钥。

首次安装会下载依赖，网络较慢时请等待。安装失败后可按错误提示处理并重新部署，已保存的配置不会被重置。此测试版仍需要完成新用户、新账号的完整验收。

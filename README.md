# 大肥鱼云端部署 · TOM

基于 [AstrBot](https://github.com/AstrBotDevs/AstrBot) 的 QQ 机器人安装与开通方案：在自己的阿里云轻量服务器上安装，网页设置密码、激活套餐模型、扫码绑定 QQ。无需安装 DSH，也不需要本地电脑一直开机。

当前版本 **1.1.0-beta3**（测试版），大肥鱼插件 **1.1.1**，AstrBot **4.29.4**。GitHub 提供源码、模板和安装包下载；机器人、后台、聊天及记忆运行在使用者自己的服务器上。

## 开始部署

**[点击进入阿里云一键部署](https://ros.console.aliyun.com/cn-beijing/stacks/create?templateType=url&templateUrl=https%3A%2F%2Fraw.githubusercontent.com%2Fhhyyzz99%2Fdafeiyu-cloud%2Fv1.1.0-beta3%2Fdeployment%2Fdafeiyu-ros-1.1.0-beta3.json&isSimplified=true&stackNamePrefix=Dafeiyu&pageTitle=%7B%22zh-cn%22%3A+%22%E4%B8%80%E9%94%AE%E9%83%A8%E7%BD%B2%E5%A4%A7%E8%82%A5%E9%B1%BC%22%7D&productNavBar=disabled)** · [下载当前版本](https://github.com/hhyyzz99/dafeiyu-cloud/releases/tag/v1.1.0-beta3)

1. 准备已适配的同款：阿里云轻量应用服务器，**北京地域、智能体专用型 2 核 6 GB、30 GB 系统盘、Hermes Agent 应用镜像**。确认购买页包含模型调用额度；费用和供应情况以实际订单为准。
2. 在服务器概览复制 **实例 ID**。打开上方链接，在自己的阿里云账号中填写实例 ID，阅读证书协议，同意后创建资源栈。模板查询已有实例并安装程序，不会购买或重置服务器。
3. 等待部署完成，在“输出”确认 `InstallStatus` 为安装成功，再打开 `OpenYourFish`。**这个地址含一次性开通码，只供本人使用，请勿公开。**
4. 设置至少 12 位、包含英文字母和数字的管理密码。账号固定为 `fish`。
5. 从本实例概览的“API Key 管理”复制套餐模型密钥，粘贴到向导，点击“验证并激活”。不要填写阿里云账号 AccessKey。
6. 用管理机器人的手机 QQ 扫码并确认，等待网页显示“QQ 接入运行中”。在 QQ 实际发消息，收到回复后再点击网页确认按钮。

公网 80、443 需要可访问，443 不能被其他网站占用。安装需要联网下载依赖；同款 Hermes 镜像原有 80 端口服务会按兼容方式处理。安装失败时先看错误提示，不要反复重置系统。

部署后：向导为 `https://自己的服务器公网IP/setup/`，完整后台为 `https://自己的服务器公网IP/`。管理密码和模型密钥都在自己的服务器上配置，不提交到此仓库。

## 人设与记忆

后台“人格设定” → “大肥鱼” → 三点菜单 → 编辑“系统提示词” → 保存。默认配置采用“大肥鱼”；创建新的人格后需到“配置文件 → AI → 人格”选择。多个聊天使用同一份人格时，修改会影响它们后续的回复。可发送 `/new` 开启新对话测试，不会清空长期记忆。

| 指令 | 用途 |
| --- | --- |
| `/鱼帮助` | 查看指令 |
| `/鱼状态` | 当前会话配置模型、自动记忆开关、互动次数、记忆数量 |
| `/鱼记住 称呼=小明` | 手动保存，同名可更新 |
| `/鱼记忆`、`/鱼记忆 2` | 分页查看记录 |
| `/鱼忘记 称呼` | 删除指定记忆 |
| `/鱼自动记忆 开启`、`/鱼自动记忆 关闭` | 控制后续自动保存；默认关闭，关闭不删除已有记录 |
| `/鱼清空记忆 确认` | 删除自己在当前范围的全部长期记忆 |

群里使用时先从 QQ 的 @ 列表选择机器人。记忆按接入、群/私聊和发言者隔离；新对话不清空长期记忆，删除长期记忆不删除聊天原文。自动整理可能记错，请用 `/鱼记忆` 核对。相关消息与记忆会发送给模型服务生成回答，不是离线模型。

## 功能与验证范围

- 已整合 QQ 私聊/群聊、大肥鱼人格、手动记忆、可选自动记忆、关键词检索、时间及算术工具。
- `/鱼状态` 显示配置模型，不是上一条实际请求使用模型的证明。
- 尚未接入 B 站评论、语音、图片理解、联网搜索或电脑操作。
- 演示服务器的部署、模型接入、QQ 收发和群友 @ 已有实测；2026-11-05 收到另一账号部署成功反馈。大量用户同时部署和长期运行尚未全面验证。
- 模型调用使用所购买实例的套餐额度，有用量上限；模型名称和可用性以供应方为准。

## 下载与校验

Release 中的安装包与已验证版本逐字节一致。ROS 模板固定版本和 SHA-256，下载校验通过后才执行。GitHub 无法访问时可能导致部署失败；请保留原始报错，不要通过关闭 HTTPS 校验或使用未知镜像站绕过。

```text
3df9c818617d247113c6fab01b92889caf1543f211e4f42e0c00bc2016bd0654  dafeiyu-web-1.1.0-beta3.run
```

这个安装包用于首次部署或相同版本失败后的续装，**不是已安装实例的升级工具**。发布新版本不会自动覆盖其他用户的人设、聊天和记忆。

## 源码与复现

- `source/`：安装包内的完整源码和测试，保留原文件以复现既有安装包。
- `deployment/`：GitHub 下载版 ROS 模板及公开部署链接。
- `tools/prepare_release.py`：从源码复现安装包，并生成固定版本的 GitHub 部署入口。
- `release.json`：已验证版本与安装包指纹。

```text
python tools/prepare_release.py --repository hhyyzz99/dafeiyu-cloud --output build
python -m unittest discover -s tools -p "test_*.py"
python -m unittest discover -s source/tests -p "test_*.py"
python -m unittest discover -s source -p "test_*.py"
```

历史安装包内的文档和可选说明页保留了早期版本文字；当前操作入口以本 README 和 `deployment/` 为准。不要直接上传整个本地工作目录、服务器备份或日志。提交问题时请隐藏密码、模型密钥、QQ secret、一次性开通链接和私人聊天。
